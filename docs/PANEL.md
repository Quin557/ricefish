# 面板使用说明

面板是本项目日常管理的主入口。启动后日志会打印地址和 Token，浏览器打开
`http://127.0.0.1:8721`，用 Token 登录即可。

## 导航

| 页面 | 用途 |
|---|---|
| 概览 | 连接状态、消息/模型用量、白名单入口、最近消息 |
| 会话 | 只显示白名单里的群和私聊；搜索、开关、进入详情 |
| 白名单 | 从 NapCat 已知群/好友里选，或手动输入号码 |
| 成员 | 按会话分组的人物档案，支持搜索和筛选 |
| 记忆 | 全局长期事实，可搜索、归档、删除 |
| 人设 | 全局 / 群 / 私聊三层人设 |
| 设置 | 运行模式、主动插话、限流、并发、当前配置 |
| 日志 | 最近日志（只读） |

## 白名单

- 进入「白名单」，群聊和好友各一栏。
- 点「从已知群聊里选择」会列出 NapCat 拉到的群（按名字搜索），点「加入」即可；
  也可以直接在输入框填群号/QQ，逗号或换行分隔，批量加入。
- 移除点「移除」；清空需要勾选「我确认清空」再点「清空」。
- 空白名单是允许的，但页面会红色警告：机器人不会回复任何人。
- 移除/清空只停止回复，**不会删除聊天记录和记忆**。
- 页面顶部会显示当前生效来源：
  - 「面板（数据库）」：以面板保存的名单为准；
  - 「配置文件（.env / bot.yaml）」：还没在面板保存过，使用启动时的种子。
- `.env` 的 `RICEFISH_ALLOWED_GROUPS/FRIENDS` 只建议做首次种子；之后在面板改。

## 会话

- 默认只列白名单里的会话；`显示全部（含未授权）` 是排查用的，未授权会话不会回复。
- 私聊只要加入白名单就会出现在列表里，不用等对方先发消息。
- 点会话名进入详情：开关、主动插话、人设入口、成员快编、长期记忆、最近消息。

## 成员、备注、亲密度

- 会话详情的成员表里可以直接改「备注」，拖动「亲密度」滑杆（或点 ±1/±5），
  点「保存」或让备注失焦自动保存，页面不会跳走。
- 「人工确认」勾上后，记忆抽取器不再覆盖这个人的档案；取消勾选会解锁。
- 「完整档案」进入单人页：全部字段、亲密度、备注、「她眼中的你」预览、
  相关记忆（可归档/删除）、这个人的最近消息，以及「还记着的事」。
- 「还记着的事」是抽取器从聊天里记下的约定/计划/没聊完的话题；可以点「完成」或「删除」。
  主动陪伴和普通聊天都会参考它，但提示词要求别像查岗。
- 亲密度只是提示词里的关系参考：0–20 陌生、21–40 眼熟、41–60 熟人、
  61–80 亲近、81–100 很熟。

## 人设

- 全局人设是底座；群人设只在该群生效；私聊人设只对某个人生效。
- 私聊人设存在 `config/personas/private/<QQ>.md`，会以
  「【你和这个人的单独设定】」注入私聊提示词，不会带进群聊。
- 真实群号/QQ 命名的人设文件已加入 `.gitignore`，只保存在本地，不会上传。
- 保存后下一条消息立即生效（文件按 mtime 缓存）。

## 主动陪伴

- 「设置 → 主动陪伴」是**总开关**，只管私聊的主动接话。
- 逻辑：最后一条是对方发的，隔 `idle_minutes`（当前配置 60 分钟）没动静，就主动发一条；
  最后一条是机器人发的，隔 `follow_up_minutes`（当前配置 30 分钟）可以轻轻补一句。
- 同一会话 `cooldown_minutes`（当前 90 分钟）内不重复；每会话每天默认 5 条，
  所有会话每天合计默认 30 条；避开静默时段。
- 主动内容会参考关系/亲密度、TA 的喜好和备注、长期记忆、还没做完的事，
  偏「被记得、被在意」和轻玩笑，不是打卡问候。
- 每个会话还能单独关：会话详情里取消「允许主动陪伴/插话」，
  或管理员发 `/主动 关`；`/主动 全局 关` 关掉所有私聊。
- 群聊的「主动插话」是上面「运行模式」里的独立开关，参数是概率/最小间隔/每日上限/
  相关度阈值；想更主动就把概率调到 0.3、阈值调到 0.5。
- 主动消息也会写进聊天记录，下一轮上下文能看到，不会"发完就忘"。

## 表情库

- 群友发图会自动进库；内置表情在启动时导入。按 hash 去重。
- 「表情」页可以按情绪/标签搜索、改标签、停用、删除，也能看到使用次数。
- 「自动打标 5 张」会用视觉模型给还没有标签的表情补情绪/实体标签；一次少量，避免烧钱。
- 每张图可以设「全局池 / 群 / 私聊」归属，发送时优先当前会话池，再退回全局。
- 内置素材的 source/license 从 `assets/emoji/manifest.json` 自动灌入；群友图标记为本地保存、不随项目分发。
- 发送时按当前情绪/场景挑一张，同一会话会避开上一张；群聊和私聊共用全局池。

## 关系时间线 / 情节记忆

- 会话详情里有「最近情节」和「关系时间线」：
  - 情节：这段聊了什么、情绪、话题；
  - 时间线：第一次、约定、冲突、和好、里程碑、梗。
- 这些由提取器在记忆抽取时写入；普通聊天和主动陪伴都会参考，但提示词要求别硬提。
- 人物页的「还记着的事」是更具体的约定/计划，可以「完成」或「删除」。

## 设置

- 白名单不再用逗号文本框，统一在「白名单」页管理。
- 运行模式、试运行、主动插话、限流、并发等热改项保存后立即生效；
  其余参数改 `config/bot.yaml` 后重启。
- 每项后面的「面板 / 配置文件」徽章表示当前值来自哪里。

## 常见问题

- **看不到某个群？** 先在「白名单」加入；如果 NapCat 没连上，列表里可能没有名字，
  可以手动输入群号。
- **改了没生效？** 白名单和热改项立即生效；人设按文件 mtime 生效；
  模型/端口等要重启。
- **想把某个会话静音？** 会话详情里关「启用」，或发 `/静音`。
- **想清空某个人的记忆？** 成员页/人物页可以逐条归档或删除长期事实；
  聊天原文目前不提供一键删除。
