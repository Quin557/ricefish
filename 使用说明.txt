icefish 快速开始（Windows）

这是一个 QQ 聊天机器人。发行包不是装好就能直接聊天的绿色版，
第一次运行仍然要双击 start.bat，由脚本帮你安装和配置。

1. 准备
   - Windows 10/11 电脑
   - 一个 QQ 小号（不要用主号）
   - 一个 DeepSeek API Key（https://platform.deepseek.com/）

2. 解压
   把 ricefish-v0.3.0.zip 解压到 D:\ricefish 这类纯英文路径，
   路径里不要有中文或空格，确保 start.bat 就在这个文件夹里。

3. 双击 start.bat
   如果 Windows 提示“已保护你的电脑”，点“更多信息”->“仍要运行”。
   杀毒软件拦截时，把整个文件夹加入信任区。

4. 按弹窗填写
   - DeepSeek API Key：sk- 开头的那串
   - 主人 QQ：你自己的 QQ 号
   - 允许说话的群：群号，多个用逗号隔开，不知道可以留空
   - 私聊白名单：允许私聊它的人，一般填你自己

5. 扫码登录
   用手机 QQ 的小号扫描二维码（绝对不要用主号），手机上确认登录。

6. 打开管理面板
   脚本会自动打开 http://127.0.0.1:8721
   在“白名单”里把群和好友加进去；白名单为空时它谁都不理。

7. 先试运行，再正式说话
   默认是试运行，只写日志不真的发消息。测试没问题后，
   到面板“设置”里把“试运行”改成“真实发送”，保存。

以后每次启动：双击 start.bat。
停止：关掉写着 ricefish 和 NapCat 的黑色窗口。

数据位置：
  data\   聊天记录、记忆、日志、表情、语音包
  .env    API Key、QQ、白名单种子、面板 token
备份或换电脑时，复制 data 文件夹和 .env 即可。

出问题：
  先看 setup.log 和 data\logs\bot.log
  也可以在项目文件夹运行：start.bat -CheckOnly
  详细说明看 README.md 的“出问题怎么办”。

隐私：
  .env、data\、vendor\、二维码、日志、个人人设都不会上传到 GitHub。
  不要把自己的 .env 或 data 文件夹发给别人。
